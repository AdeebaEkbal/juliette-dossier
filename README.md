# Classified Dossier: Sector 45

**Live Demo:** [View the Classified Dossier](https://adeebaekbal.github.io/juliette-dossier/)
## About the Project
This is a web-based classified character profile layout. I built this as my first foundational project while learning HTML and CSS, bridging my interest in character development with web design. The layout simulates a secure terminal file with interactive and responsive elements.

## Features
* **CSS Keyframe Animations:** Features a dynamic typewriter effect (`steps()`, `ch` units) mimicking a terminal boot sequence.
* **Responsive Design:** Utilizes CSS media queries to ensure the absolute-positioned elements (like the "Top Secret" stamp) scale and stack cleanly on mobile devices.
* **Semantic HTML:** Built using structural tags like `<details>` and `<summary>` for interactive, collapsible data sections.
* **Custom Typography:** Integrates Google Fonts to enhance the authentic, gritty aesthetic of a classified document.

## Technologies Used
* HTML5
* CSS3 (External stylesheet, Custom Reset, CSS Variables, Media Queries)
* Git & GitHub Pages
